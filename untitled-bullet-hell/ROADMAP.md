# Roadmap

This roadmap tracks prototype-sized goals. It is intentionally flexible while the core combat is being tested.

## Current focus

- [x] Establish a runnable Godot project and single-arena boss prototype.
- [x] Establish a proposed pixel-art specification and create a small visual slice.
- [ ] Review the slice and compare native viewport against the proposed logical pixel scale.
- [x] Slow the held staff attack to a deliberate cadence.
- [x] Add multiple boss patterns with visible wind-up cues.
- [x] Increase boss projectile pressure while keeping attack telegraphs and safe lanes.
- [x] Add hit effects, a dash afterimage, and brief hit-stop.
- [ ] Playtest attack timing, projectile density, and player survivability.
- [ ] Add basic audio feedback for staff shots, hits, dashes, and boss attacks.

## Next: encounter quality

- [x] Add a boss defeat sequence and reward choice for the temporary ice-boss prototype.
- [x] Add temporary ice-themed arena decoration around the playable perimeter.
- [x] Draft a stage-based boss roster proposal before adding another boss.
- [ ] Review and approve the boss roster and art direction before expanding production assets.
- [x] Replace the prototype's script-drawn player, Warden, arena tiles/props, and projectiles with original pixel-art assets.
- [x] Add a brief movement slow when Warden frost shards hit the player.
- [ ] Give the boss clearer wind-up and recovery animation for each attack.
- [ ] Tune boss movement and the balance between attack patterns.
- [ ] Add a restart/defeat flow that makes encounter state clear.
- [ ] Approve the redesigned Stage 1 roster and art direction.
- [ ] Review the Warden visual and movement-slow counterplay before expanding its attack/animation set.
- [ ] Add the Briar Widow and Cinder Reliquary as Stage 1 roster choices.

## Later: reusable game structure

- [ ] Separate player, boss, projectile, arena, and HUD into reusable scenes.
- [ ] Move prototype tuning values into Godot resources or a central configuration.
- [ ] Define a first-stage arena theme and consistent asset scale/palette.

## Out of scope for the immediate prototype

- Large numbers of ordinary enemies or exploration rooms.
- Elaborate skill trees, currencies, or complex progression menus.
- Final story, full boss roster, or polished production art for every region.
